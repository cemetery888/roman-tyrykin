TOP1BET

Admin panel for managing agents and players for a gambling and sports betting website.

Admin Panel

Company

Snocko Technologies Co.Ltd

Role

Product Designer

TOP1BET is a management system for agents and players for a gambling and sports betting website.

Creating and editing users

The system is structured like a pyramid. At the very top is the admin, who can create shareholders, who in turn create agents of all levels and players. There are 3 levels of agents: Senior, Master Agent, and simply Agent. Each agent can create users below their level. Thus, a Senior can create agents of two levels and players, while a simple Agent can only create players. Players can only log in to the gaming site and play, which is their intended purpose.

The table clearly shows who can create whom. The table should be viewed from top to left.

Managing sub-accounts

Sub-accounts are needed for delegating certain actions, such as creating users, managing account top-ups, etc.

Specific permissions can be set for sub-accounts according to their roles.

Punishments

Users can apply punishments to their downline: suspend (pause), lock, and close. An agent's punishment leads to punishments for their downline. A user higher in level (from the upline) has the ability to lift the punishment.

Users with incomplete registration

To register, it is necessary to complete the process fully by following a special link. If this has not happened, the user appears in the corresponding list. A new link can be generated for them to complete registration, as well as apply punishments, for example, to close the user if they are no longer needed.

Current open bets

This section displays current long-term bets (sports). Bets can be cancelled if necessary. There is a search function for both users and by Bet ID.

Financial reports for downline

There are two types of reports: Simple and Detailed. The first is simpler, the second has more details. The main purpose of the report is to see who has earned what.

Managing deposits and withdrawals

There are both automatic and manual deposits and withdrawals. In the automatic process, operations performed by players on the main site must be accepted or declined, while in the manual process, the balance can be adjusted manually, conducting other operations outside the system.

Announcements on gaming and agent websites

Both websites contain a section for notifications. Mainly, notifications include changes in sporting events: bet cancellations, odds changes, etc.

Theme editor for the gaming website

The website owner can change the colour palette of the site — Primary and Secondary (the system selects light and dark shades automatically). They can also choose the layout for main pages such as Home, Slot Game, Casino, Fishing.
