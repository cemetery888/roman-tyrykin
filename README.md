# Роман Тырыкин — портфолио

Сайт-портфолио, свёрстанный по макету Port 2026 в Figma. Публикуется через GitHub Pages.

## Как устроено

- `src/data/` — тексты страниц на RU и EN.
- `src/templates/` — HTML-шаблоны, `src/assets/` — стили, скрипты и картинки.
- `node build.mjs` собирает сайт в `dist/` (без зависимостей, нужен только Node 18+).
- При пуше в `main` GitHub Actions собирает сайт и публикует его на GitHub Pages.

Адреса: RU — `/`, EN — `/en/`, кейсы — `/<кейс>/` и `/en/<кейс>/`.

## Страницы кейсов

Кейсы собираются из выгрузки макета, а не пишутся руками:

- `tools/cases/figma/` — код кадров из Figma (Desktop 1440, Tablet 800, Mobile 375 для каждого кейса и языка).
- `cd tools/cases && npm install && node convert.mjs` превращает их в `src/cases/<кейс>-<язык>.html` и `src/assets/css/cases.css` (Tailwind генерирует только используемые классы). На странице лежат три версии, нужная показывается по ширине экрана.
- Картинки кейсов — `src/assets/cases/`, превью для соцсетей — `src/assets/img/og-<кейс>.jpg`.
- После конвертации запустите `node build.mjs`.
